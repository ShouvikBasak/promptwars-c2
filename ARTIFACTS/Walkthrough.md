# Walkthrough: ElectEd India MVP

This document provides a walkthrough of the features, architecture, and implementation of the ElectEd India MVP.

## Project Vision
ElectEd India is an educational conversational tool designed to provide neutral, grounded information about the Indian election process.

## Core Features

### 1. "Ask ElectEd" Chat Interface
- **Modern UI**: A warm, welcoming, and accessible interface inspired by Khan Academy and GOV.UK.
- **Example Questions**: Small chips to help users get started with in-scope queries.
- **Responsive Design**: Fully functional across mobile, tablet, and desktop devices.
- **Accessibility**: High-contrast colors, keyboard navigability, and clear focus states.

### 2. Intelligent Backend Orchestration
- **Intent Classification**: Every user message is analyzed by Gemini to determine if it is "In-Scope" or "Out-of-Scope".
- **Grounded Responses**: In-scope queries are answered using Gemini 2.5 Flash, strictly following the provided system prompts for neutrality and accuracy.
- **Safety Guardrails**: Out-of-scope or sensitive queries are intercepted by a deterministic refusal gate.

## Technical Implementation

### Refusal Logic (The Guardrail)
If the intent classifier flags a query as out-of-scope, the backend returns a hardcoded, immutable string:
> *"This information is not available in official Election Commission of India sources."*

This string is never generated by the LLM, ensuring zero hallucination risk or tone-softening.

### Stateless Architecture
- No user accounts, no databases, and no PII collection.
- Session context is maintained by passing the last 10 messages (5 pairs) back to the model with each request.
- Deployed on **Google Cloud Run** for high scalability and secure IAM-based authentication to Vertex AI.

## Verification & Smoke Test
- **In-Scope Test**: "What is the role of the ECI?" -> Successfully returns a detailed, structured explanation of ECI responsibilities.
- **Out-of-Scope Test**: "Who should I vote for?" -> Correctly triggers the hardcoded refusal message.
- **Accessibility Test**: Confirmed keyboard tab flow and focus visibility on all interactive elements.
